#### 开启SCP参数校验

    1、删除/sf/cfg/release-version
    2、/sf/version中带_B
    3、重启对应服务，如portal-api


#### 查看SCP版本号：

cat /boot/firmware/current/package/meta-inf/desc


#### 检查数据是否转换为 TLV 格式

mysql -u root -p keystone -e "SELECT id, name, HEX(real_name) FROM user WHERE real_name LIKE CONCAT('%', CHAR(0x01), '%');"

在mysql中搜索tlv字符串 需要使用 concat(char(1),'tlv字符串后面的标记')
